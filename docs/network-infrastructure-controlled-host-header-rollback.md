# Controlled-host generated-header rollback

Use this step only after bundle Restore, hosts Restore, trust removal, and
manifest-key removal have all passed. Do not use `git checkout`, `git reset`,
or shell redirection.

## Preconditions

```powershell
Set-Location C:\Reborn
$header='C:\Reborn\client\network-shim\src\SecureClientManifestDevelopmentKeys.generated.h'
$preSha='DBEFDE1D30BDF7DAAFBD29C8D4420A2694C7907CFF371BD9352FA225A077042E'
$preBlob='929c26dfca80b54f8776056e8838e0024aa93ddc'
if((Get-FileHash $header -Algorithm SHA256).Hash -cne $preSha){
 throw 'Generated-header rollback preimage SHA-256 mismatch.'

if((& git hash-object -- $header).Trim() -cne $preBlob){

}
```
